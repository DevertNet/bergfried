# Roadmap

| # | Meilenstein | Fertig, wenn … |
|---|---|---|
| M1 | Fundament: Lima-Vorlage, `bergfriedd` als CLI (create/start/stop/delete/list) | Session per CLI starten und Claude per Remote Control vom Handy steuern |
| M2 | Datei-Anfragen: Index, `bergfried-mcp`, Kopie nach `shared/in` | `request_file` wird bestätigt und die Datei liegt in der VM |
| M3 | SSH-Broker: Agent-Socket, Freigabe mit Ablauf, Host und Key | `ssh` klappt nur während der Freigabe |
| M4 | Control-App (SwiftUI) | Alles aus M1–M3 ohne Terminal bedienbar |
| M5 | VPS-Host (Debian, SSH-Rückkanal, KVM-Check) | Session auf dem VPS mit Datei- und SSH-Freigabe vom Mac |
| M6 | Datei-Browser, Editor, „In VS Code öffnen“ | Dateien einer Session ansehen/bearbeiten |
| M7 | Handy-Freigaben (zurückgestellt) | – |
